## ADDED Requirements

### Requirement: Drag and drop tracks between categories
The system SHALL enable drag-and-drop of tracks between categories and containers.

#### Scenario: Track moved between categories
- **WHEN** user drags a track from one category to another
- **THEN** system moves the track to the target category and updates both category statistics

#### Scenario: Track added to container
- **WHEN** user drags a track to a custom container
- **THEN** system adds the track to that container and updates container statistics
